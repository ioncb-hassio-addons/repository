# Retro Web

[![Release][release-shield]][release]
![Project Stage][project-stage-shield]
![Project Maintenance][maintenance-shield]

Profile-based retro game library for Home Assistant.



## Features

- Local profiles.
- NES, SNES, Game Boy/Color, Game Boy Advance, Nintendo 64, and Arcade.
- ROM and BIOS management through Home Assistant Ingress.
- Optional username/password access from outside Home Assistant.
- External uploads disabled by default.
- Locally served EmulatorJS assets.

Retro Web does not contain or distribute ROMs or BIOS files. Only use media
that you are legally authorized to copy and emulate.
